## 🎯 Project Overview
This project was developed as part of the **HackYourFuture Denmark** software development program. The goal was to take a comprehensive, multi-breakpoint UI design from **Figma** and implement it into clean, maintainable, and responsive frontend code without relying on heavy external frameworks.

### Key Highlights:
* **Figma to Code Accuracy:** Pixel-perfect implementation following layout guidelines, typography scales, colors, and asset constraints.
* **Responsive Multi-Device Layout:** Fluid responsiveness across mobile, tablet, and desktop screens using modern CSS **Flexbox** and **CSS Grid**.
* **Accessibility (a11y) & Semantics:** Built using semantic HTML5 tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), structured heading hierarchy (`h1`-`h3`), and descriptive `alt` tags for imagery.
* **Clean CSS Architecture:** Reusable utility styles, consistent vertical rhythm, smooth hover states, and optimized media queries.
